# Граматика SIPL 0.1

Машинозчитувана граматика: [`grammar/sipl.ebnf`](../grammar/sipl.ebnf), формат ISO/IEC 14977 EBNF.

## БНФ SIPL

```
P ::= begin S end                                                  P1
S ::= x := a | S1 ; S2 | if b then S1 else S2 | while b do S
    | begin S end | skip                                           S1–S6
a ::= n | x | a1 + a2 | a1 - a2 | a1 * a2 | (a)                    A1–A6
b ::= a1 = a2 | a1 > a2 | b1 ∨ b2 | ¬ b | (b)                      B1–B5
x ::= ... M | N | ...
n ::= ... -1 | 0 | 1 | 2 | 3 | ...
```

## Як БНФ перетворено на EBNF

БНФ неоднозначна (`a1 + a2 * a3`, `S1 ; S2 ; S3` можна вивести кількома способами),
тому в EBNF пріоритети задано рівнями правил:

| Рівень (від слабшого до сильнішого) | Конструкція | Асоціативність |
|---|---|---|
| `statement` | `S1 ; S2` | ліва |
| `simple` | `:=`, `if`, `while`, `begin … end`, `skip` | — |
| `expression` | `+`, `-` | ліва |
| `term` | `*` | ліва |
| `factor` | число, змінна, `( … )` | — |
| `condition` | `∨` | ліва |
| `disjunct` | `¬`, `=`, `>`, `( … )` | — |

Рішення, які варто знати:

1. **`;` слабша за `if` і `while`.** Тіло `while` і гілки `if` — це один оператор.
   `while b do S1; S2` означає `(while b do S1); S2`. Кілька операторів у тілі треба
   групувати `begin … end`.
2. **`;` розділяє, а не завершує.** `begin X := 1; end` — помилка.
3. **Дужки в умовах.** `(` на початку умови може відкривати і `(b)` (B5), і `(a)` (A6),
   як у `(X + 1) > 2`. Парсер дивиться на токен після парної `)`: якщо це `=`, `>`, `+`,
   `-` або `*`, дужки належать арифметичному виразу, інакше — умові.
4. **Від'ємні числа** (правило `n ::= ... -1 | 0 | ...`) — лише літерали: `X := -1`,
   `X - -1`. Унарного мінуса для змінних у БНФ немає, тому `-Y` — помилка.
5. **Тип чисел** — 64-бітне ціле зі знаком.

## Лексика

| Токен | Запис |
|---|---|
| Ключові слова | `begin end if then else while do skip` |
| Диз'юнкція | `∨` або `or` |
| Заперечення | `¬` або `not` |
| Присвоювання | `:=` |
| Операції | `+`, `-` (також `–`, `−`), `*` (також `∗`, `×`), `=`, `>` |
| Дужки, розділювач | `(`, `)`, `;` |
| Змінна | `[A-Za-z_][A-Za-z0-9_]*`, крім ключових слів; регістр має значення |
| Число | `[0-9]+` |

Пробіли, табуляції та переведення рядка ігноруються. Коментарів у SIPL немає.

## AST

Парсер будує власні вузли (`src/ast.rs`), кожен із `Span` — діапазоном байтів у вихідному
тексті, з якого обчислюються рядок і колонка для діагностики.

| Синтаксична категорія | Тип у коді |
|---|---|
| Prog | `Program` |
| Stm | `Statement` |
| Aexp | `ArithExpr` |
| Bexp | `BoolExpr` |
| Var | `Variable` |
| Num | `ArithExprKind::Number` |

| БНФ | Вузол |
|---|---|
| P1 | `Program { body }` |
| S1 | `StatementKind::Assign { variable, value }` |
| S2 | `StatementKind::Sequence(S1, S2)` |
| S3 | `StatementKind::If { condition, then_branch, else_branch }` |
| S4 | `StatementKind::While { condition, body }` |
| S5 | `StatementKind::Block(S)` |
| S6 | `StatementKind::Skip` |
| A1–A5 | `ArithExprKind::Number`, `Variable`, `Binary { op: Add / Subtract / Multiply }` |
| A6, B5 | окремого вузла немає, дужки входять у `span` внутрішнього виразу |
| B1–B4 | `BoolExprKind::Compare { op: Equal / Greater }`, `Or`, `Not` |

Текстовий вигляд AST (використовується в golden-тестах) — S-вирази:
`(; (:= R 1) (while (> Y 0) (begin ...)))`.
