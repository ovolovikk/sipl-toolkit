# Граматика

Машинозчитувана граматика: [`grammar/sipl.ebnf`](../grammar/sipl.ebnf) (ISO EBNF).

```
P ::= begin S end
S ::= x := a | S1 ; S2 | if b then S1 else S2 | while b do S | begin S end | skip
a ::= n | x | a1 + a2 | a1 - a2 | a1 * a2 | (a)
b ::= a1 = a2 | a1 > a2 | b1 ∨ b2 | ¬ b | (b)
```

БНФ неоднозначна, тому в EBNF задано пріоритети (від сильнішого):
`*`, потім `+ -`, потім `= >`, `¬`, `∨`, оператори, `;`. Усі бінарні операції лівоасоціативні.

Що з цього випливає:

- `while b do S1; S2` — це `(while b do S1); S2`; кілька операторів у тілі беруть у `begin … end`;
- `;` розділяє оператори: `X := 1; end` — помилка;
- `-1` — число, а `-Y` — помилка: унарного мінуса в БНФ немає;
- у `(X + 1) > 2` дужки належать виразу, у `(X > 1) ∨ …` — умові; парсер
  вирішує за токеном після `)`.

Лексика: ключові слова `begin end if then else while do skip`; `∨` або `or`, `¬` або `not`;
також приймаються `–`, `−`, `∗`, `×`. Змінні — `[A-Za-z_][A-Za-z0-9_]*`. Коментарів немає.

AST (`src/ast.rs`): `Program`, `Statement`, `ArithExpr`, `BoolExpr`, `Variable` —
відповідно `Prog`, `Stm`, `Aexp`, `Bexp`, `Var`. Кожен вузол знає своє місце в тексті (`span`).
