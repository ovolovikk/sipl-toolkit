# Інтерпретатор SIPL

Код: `src/state.rs`, `src/interpreter.rs`.

## Стан

Стан — скінченне відображення змінних у цілі числа, наприклад `[R ↦ 1024, X ↦ 2, Y ↦ 0]`.
Змінна, якої немає в стані, не має значення: спроба її прочитати — помилка виконання,
а не нуль за замовчуванням. Так семантика програми є частковою функцією над станами.

Числа — 64-бітні цілі зі знаком. Переповнення при `+`, `-`, `*` — помилка виконання.

## Виконання

Інтерпретатор рекурсивно обходить AST. Кожен оператор перетворює стан, кожен вираз
обчислюється в поточному стані.

| Конструкція | Композиція | Що робить інтерпретатор |
|---|---|---|
| `x := a` | `ASˣ(a)` | обчислює `a`, записує результат у `x` |
| `S1 ; S2` | `S1 · S2` | виконує `S1`, потім `S2` у новому стані |
| `if b then S1 else S2` | `IF(b, S1, S2)` | обчислює `b`, виконує лише одну гілку |
| `while b do S` | `WH(b, S)` | поки `b` істинна, виконує `S` |
| `begin S end` | `S` | виконує `S` |
| `skip` | `id` | стан не змінюється |
| `a1 + a2`, `a1 - a2`, `a1 * a2` | `S²(add / sub / mult, a1, a2)` | обчислює обидва операнди, потім операцію |
| `a1 = a2`, `a1 > a2` | `S²(eq / gr, a1, a2)` | обчислює обидва операнди, порівнює |
| `b1 ∨ b2` | `S²(or, b1, b2)` | обчислює **обидва** операнди |
| `¬b` | `S¹(neg, b)` | обчислює `b`, заперечує |

**`∨` строга.** Суперпозиція визначена, лише коли визначені всі аргументи, тому
`X = 0 ∨ Y > 0` у стані `[X ↦ 0]` — помилка (немає `Y`), хоча ліва частина вже істинна.
Короткого обчислення, як `||` у C, немає.

**Невибрана гілка `if` не обчислюється.** `if X > 0 then Y := 1 else Y := Z` у стані
`[X ↦ 1]` завершується успішно, хоча `Z` невизначена.

## Ліміт ітерацій

У SIPL немає рекурсії, тож не завершитися може лише цикл `while`: усі інші конструкції
виконуються скінченну кількість разів. Тому інтерпретатор рахує виконання тіл усіх циклів
програми і зупиняється з помилкою, коли сума перевищує ліміт (за замовчуванням 1 000 000).
Помилка вказує на умову того циклу, на якому ліміт вичерпано.

Ліміт — евристика: програма, якій потрібно більше ітерацій, теж буде зупинена. Загалом
перевірити, чи завершиться програма, неможливо (проблема зупинки).

## Помилки виконання

| Помилка | Приклад | Де вказує |
|---|---|---|
| змінна не має значення | `X := Y + 1` у `[]` | на `Y` |
| переповнення | `X + 1` при `X = 9223372036854775807` | на весь вираз `X + 1` |
| ліміт ітерацій | `while 1 > 0 do skip` | на умову `1 > 0` |
