# Інтерпретатор

Стан — відображення «змінна → ціле число», наприклад `[R ↦ 1024, X ↦ 2]`.
Числа 64-бітні, переповнення — помилка.

Кожна конструкція виконується так, як каже її композиція:

| SIPL | Композиція | Виконання |
|---|---|---|
| `x := a` | `ASˣ(a)` | обчислити `a`, записати в `x` |
| `S1 ; S2` | `S1 · S2` | `S1`, потім `S2` |
| `if b then S1 else S2` | `IF(b, S1, S2)` | лише одна гілка |
| `while b do S` | `WH(b, S)` | поки `b` істинна — `S` |
| `skip` | `id` | нічого |
| `b1 ∨ b2` | `S²(or, b1, b2)` | обчислюються **обидві** частини |

Рішення:

- змінна без значення — помилка, а не нуль (семантика часткова);
- `∨` строга: `X = 0 ∨ Y > 0` без `Y` — помилка, хоча ліва частина істинна;
- невибрана гілка `if` не обчислюється;
- рахуються лише ітерації циклів (за замовчуванням до 1 000 000): рекурсії в SIPL
  немає, тож не завершитися може лише `while`. Помилка вказує на його умову.
