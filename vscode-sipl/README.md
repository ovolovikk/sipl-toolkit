# SIPL для VS Code

Підсвітка синтаксису та сніпети для мови SIPL.

- файли `.sipl` розпізнаються автоматично;
- підсвічуються ключові слова, змінні, числа, оператори (`¬ ∨ ∗ −` теж), а символи
  поза мовою, як `<`, позначаються як помилка;
- `begin`/`end` і дужки підсвічуються парами, після `begin`, `do`, `then`, `else`
  наступний рядок отримує відступ;
- сніпети: `program`, `begin`, `while`, `if`, `assign`.

У SIPL немає коментарів, тому команди «закоментувати рядок» теж немає.

Встановлення з файлу: `code --install-extension sipl-0.1.0.vsix`.
